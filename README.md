# 📈 202611 股票技術分析工具

輸入股票代號，自動顯示技術指標圖表和簡單訊號，支援美股及港股。

🔗 網站：https://hkstock.streamlit.app/

## 功能

- 股價 + MA20 / MA50 / MA200
- 保力加通道（Bollinger Bands）及通道寬度
- RSI14
- MACD
- 成交量
- 系統訊號：買入觀察 / 賣出觀察 / 持有觀察
- 20 個快捷股票按鈕
- 區間可選 3 個月至 5 年

## 使用方法

1. 開啟網站
2. 輸入股票代號，例如 `AAPL`、`0700.HK`、`700.HK`，或按快捷按鈕
3. 揀選區間
4. 查看圖表和摘要

## 技術

Python、Streamlit、yfinance、Plotly

資料來源：Yahoo Finance
